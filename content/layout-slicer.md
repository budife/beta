## Layout Slicer

Slice a full JPG/PNG email layout into ordered image assets and generate a simple table-based eDM HTML layout.

:::details What it does

- Drop a single JPG or PNG layout.
- Add horizontal slice lines by clicking the preview.
- Drag or remove slice lines.
- Add optional links per slice.
- Preview the generated email layout.
- Download HTML and image assets, or save everything into a local folder.
:::

:::details Local-first behavior

Images are processed in your browser with Canvas. Files are not uploaded to eDM Helper or any third-party service. Saving to folder only writes to the folder you explicitly choose in the browser.
:::

:::details Best use

Use this for fast slicing of image-heavy eDM layouts. Start with horizontal slices, then add links only to slices that need CTA tracking.
:::
